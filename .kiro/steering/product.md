# Willowbrook Clothing - Product Overview

Willowbrook Clothing is a premium custom clothing platform that allows customers to browse, customize, and order personalized apparel with real-time design previews.

## Core Features
- **Product Catalog**: Browse clothing with category filtering
- **Customization Studio**: Size, color, and embroidery options with live preview
- **Shopping Cart**: Multi-item cart management
- **Order Management**: Full order lifecycle tracking
- **User Authentication**: Secure JWT-based auth system
- **Admin Dashboard**: Complete admin panel with analytics, order management, and user administration

## Business Model
- B2C custom clothing platform
- Real-time customization with visual feedback
- Stripe payment integration
- Order fulfillment tracking
- Admin oversight and management tools

## Target Users
- **Customers**: End users browsing and customizing clothing
- **Admins**: Platform administrators managing products, orders, and users
